## Lucide icons

Raddykall Puzzle embeds selected SVG path definitions from [Lucide](https://github.com/lucide-icons/lucide), an open-source icon set used for the game's small utility and settings icons. The SVGs are embedded in `www/index.html` so they work offline and do not require a remote CDN at runtime.
